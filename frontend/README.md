# 飞图前端

本机环境连通性页面，使用 React、TypeScript 与 Vite。此阶段不包含行情采集、行情处理或业务展示。

## 本机运行

在仓库根目录执行 `nvm use`，使用 Node 24.18.0；本项目固定 pnpm 11.9.0。

```sh
cd frontend
pnpm install --frozen-lockfile
pnpm dev
```

访问 http://127.0.0.1:5173。开发服务器将 `/api` 转发到 `http://127.0.0.1:8080`；需要同时运行 Go 后端。端口被占用时立即退出，不会静默切换端口。

```sh
pnpm typecheck
pnpm build
```

`pnpm preview` 仅预览构建文件，不提供开发代理；部署构建文件时需由同源服务器转发 `/api`。

## 状态行为

- 读取真实 `GET /api/status`，验证响应结构及汇总与各服务状态的一致性。
- 支持 HTTP 200 和携带完整状态响应的 HTTP 503；其他 HTTP 错误、无效数据及网络失败显示检查失败，所有当前服务改为未知。
- 已有数据后再次请求失败时，保留最近成功获取时间并标记过期，不继续显示旧的成功卡片。
- 手动刷新与每 15 秒自动刷新共用请求互斥；页面隐藏时跳过定时刷新，15 秒超时，卸载时取消请求。
- 无外部字体、遥测或模拟成功数据；支持窄屏、键盘操作与减少动画偏好。

已验证：Node 24.18.0 下 `pnpm run build`（包含 TypeScript 检查）成功。真实服务连通与页面集成验证由仓库启动流程完成。
