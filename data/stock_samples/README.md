# A 股历史日线样本

这些是从 BaoStock 下载的真实历史行情返回值，供本项目离线回放、清洗、入库与文件对账练习；没有生成或注入 mock 行情。只做一次性样本准备，没有搭建在线采集服务。`raw/` 保留源字段和字符串值，仅序列化为 UTF-8 CSV，没有复权、填空、改价、去重或排序。

## 范围与来源

- 下载日期：2026-10-06（Asia/Kuala_Lumpur）；逐文件时间及 SHA-256 见 `manifest.json`。
- 来源：[BaoStock](https://baostock.com/)，Python SDK `00.9.40`，免注册默认登录。
- 请求：`query_history_k_data_plus`，2024-01-01 至 2025-12-31，日频 `d`，`adjustflag=3`（不复权）。完整参数和返回列写入 manifest。
- 证券：20 只沪深 A 股，代码如下。它们是手选练习样本，不是历史指数成分或全市场代表样本。
- 交易日历：同源 `query_trade_dates`，保留自然日及交易日标志。
- 实际结果：20 个行情 CSV，各 485 行，共 9,700 行，日期为 2024-01-02 至 2025-12-31；日历 731 行，含 485 个交易日。目录约 1.1 MB。下载后验证通过，没有发现本检查覆盖的异常。

## 字段口径

| 字段 | 含义与单位 |
| --- | --- |
| date | 交易日期，YYYY-MM-DD；按中国交易市场日期理解，Asia/Shanghai |
| code | BaoStock 证券代码，保留交易所前缀和前导零 |
| open / high / low / close | 开高低收，人民币元，不复权 |
| preclose | 源端前收盘价；除权除息日不要直接假设等于上一行 close |
| volume | 成交量，股，不要再乘以 100 |
| amount | 成交额，人民币元 |
| adjustflag | 3 表示不复权，原样保留 |
| turn / pctChg | 换手率 / 涨跌幅，百分数值；1 表示 1%，不是 100% |
| tradestatus | 1 正常交易，0 停牌 |
| isST | 1 是 ST，0 否 |
| calendar_date / is_trading_day | 日历日期 / 1 交易日、0 非交易日 |

口径参考 [BaoStock API 文档入口](http://baostock.com/baostock/index.php/Python_API文档)。该入口在本次网页工具中未能完整展示，字段说明同时核对了[公开 API 文档副本](https://github.com/zxygithub/baostock/blob/master/docs/pythonAPI.md)及 SDK 实际返回；副本不是交易所原始规范。未核验源端最初交易所供应商，也没有用第二家供应商证明每个价格准确。

## 离线验证与使用

在仓库根目录运行：

```sh
python3 data/stock_samples/verify.py
```

检查文件哈希、记录数、日期可解析性、日期顺序、重复日期、与所下载日历的覆盖差异、代码、复权标志，以及正常交易记录的 OHLC 关系和非负量额。下载后的检查结果保存在 `validation.json`。停牌记录跳过价格约束，原始状态和空值仍保留给未来清洗模块处理。

回放时按文件名确定证券，逐行发送原始字段，外层再加批次、来源、事件 ID、回放时间等消息信息。CSV 行数和哈希可作为入库对账基准。故障注入请写入单独派生数据或在回放时执行，不要修改 `raw/`。

## 限制

- 数据下载时点的历史快照可能已经包含源端修订，不是“当日能看到什么”的时点数据集。
- 不含公司行动与复权因子，暂时不支持正确的复权收益研究。
- 不含完整证券主数据、退市股票池及特殊交易规则，不能验证全市场完整性。
- 日历与行情同源，当前检查属于文件完整性与内部一致性检查，不是独立跨源对账。
- 不复权序列可能因公司行动跳变，不能仅按相邻收盘涨跌判异常。
- 公开接口可下载不等于已获商业再分发授权。本次用于个人学习；没有核实对外行情服务授权，也没有把 SDK 的开源许可当作数据许可。

没有提供持续抓取器。今后需要替换样本时，可根据 manifest 内的方法和参数重新下载并生成新的批次目录，保留这份快照用于可复现实验。
